З 21.10.2026 модель сортувальника — **qwen3.5:9b** (Ollama, 6.6 ГБ Q4_K_M) замість gemma4-vram-ram (gemma4:e4b). Дефолт у config.py і в обох .env (корінь + dist).

- Потрібна **Ollama ≥ 0.40** (0.23 давала 412 «requires newer version»). Оновлення: `winget upgrade --id Ollama.Ollama`. Після оновлення список моделей був порожній.
- Ollama **не передає нативне відео** (capabilities qwen3.5: completion/vision/tools/thinking, без video; API має лише `images`). Користувач вирішив лишити кадри, без vLLM.
- `think` у запиті: перемикач у Налаштуваннях («Режим думання моделі»), `config.json["ollama_think"]`, дефолт False. З think=on у 3-7 разів повільніше (6-18с/фото проти ~2.5с) і не точніше. Якщо модель не підтримує think → 400 → повтор без параметра.
- `format` = JSON-схема {is_trash, reason}, timeout 300с.
- Відео: кадрів = clamp(ceil(тривалість/3с), 4, 12), з центрів рівних відрізків (не 0-й і не останній кадр), дедуп майже однакових, 768px (≤6 кадрів) / 640px, мітки часу в промпті. OpenCV 5 відкриває кириличні шляхи напряму — копіювання в TEMP прибрано (fallback hardlink у `<диск>:\.pc_control_tmp`, потім копія).
- Файли з крапкою (`.pending-*`, `.trashed-*` — службові Android, приходять через Syncthing; папки мають `.stfolder`) пропускаються.

**Чому:** gemma викинула 49 файлів, які користувач вручну повернув (тварини, їжа, виставки, PSP, Чумацький шлях) — вигадувала правило «без особистого контексту». qwen3.5 think=off: 21/21 таких файлів правильно залишено; синтетичні скріншот/запис екрану/«кишеня» → сміття.

**Промпти редагуються без перезбірки:** `dist\prompts\photo.txt` / `video.txt` (+README з підстановками {filename},{num_frames},{duration},{timeline}). Створюються зі стандартних (`sorter_prompts.PROMPT_IMAGE/VIDEO`) при старті, читаються заново на кожен файл (`sorter_prompts.load`, utf-8-sig, фолбек cp1251, порожній → стандарт). У Налаштуваннях: кнопки «Промпт для фото/відео» (Блокнот) + «Скинути до стандартних». УВАГА: зміна стандартних текстів у коді НЕ потрапить користувачу, поки він не натисне «Скинути» (файл має пріоритет). `prompts/` у .gitignore.

**Уподобання користувача щодо сортування (21.10.2026):** пейзажі/небо/зорі — ЗАВЖДИ залишати («я люблю пейзаж фоткати»); фото увімкненого екрана (гра, меню, консоль) і товар у магазині з цінником — сміття, навіть якщо це техніка. У промпті фото це два пріоритетні правила ЕКРАН/МАГАЗИН (виняток — живі люди в кадрі). Схема відповіді: `reason` ПЕРШИМ, потім `is_trash` (інакше було «is_trash:false, reason: скріншот гри»). Тест 24/24 на розміченому наборі.

**Як застосувати:** для тестів моделі є розмічений набір — рядки `ПОВЕРНЕНО` у dist\sorter_log.txt (хибні «сміття»). Див. [[build-and-tooling-paths]].
