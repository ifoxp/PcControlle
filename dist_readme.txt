PC Control — керування ПК з телефона
=====================================

ВСТАНОВЛЕННЯ
1. Розпакуй цей архів у зручну постійну папку (напр. C:\PC Control\).
   НЕ запускай прямо з архіву — спочатку розпакуй.
2. Запусти "PC Control.exe".
3. При першому запуску:
   - зʼявиться вибір функцій (сортувальник фото, гучність, задачі, авто-вимкнення) —
     познач те, чим користуватимешся;
   - програма згорнеться в іконку біля годинника.
4. Постав мобільний застосунок (APK) на телефон і відскануй QR із панелі
   (правий клік на іконці в треї → Відкрити панель → вкладка «Пристрої»).

ПЕРШИЙ ЗАПУСК СТВОРИТЬ ПОРУЧ:
   .env, config.json — твої налаштування;
   cert.pem/key.pem — TLS-сертифікат;
   devices.json — паровані телефони;
   логи та стан сервісів.
Ці файли — особисті, їх не треба нікому передавати.

ПРАВА АДМІНІСТРАТОРА
   Для температури CPU в моніторингу та деяких дій увімкни права у налаштуваннях
   (панель → Огляд/Налаштування). Автозапуск з правами — там само.

ДОСТУП ІЗ ІНТЕРНЕТУ (необовʼязково)
   За замовчуванням працює в локальній мережі. Для доступу ззовні налаштуй
   Cloudflare-тунель у налаштуваннях (потрібен токен тунеля).
