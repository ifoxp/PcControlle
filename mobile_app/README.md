# PC Control — мобільний пульт (Flet, Android)

Динамічний «пульт ПК»: сітка команд 4-в-ширину, яка **будується з `/manifest`**.
Нова команда на ПК → кнопка «Оновити» в додатку → нова плитка. Додаток не треба
перевидавати.

## Як це працює

1. **Парування.** На ПК: *Панель → Пристрої* показує QR (host+port+PIN+fingerprint).
   У додатку встав код QR (або введи вручну) → додаток шле `POST /pair` за PIN →
   отримує **per-device Bearer-токен** і зберігає ПК.
2. **TLS-pinning.** Додаток довіряє серверу не через публічний CA, а звіряючи
   **SHA-256 fingerprint** сертифіката (з QR). MITM неможливий.
3. **Динамічна сітка.** `GET /manifest` віддає список команд із типом віджета.
   Додаток малює плитки; кожен тип має вбудовану реалізацію.

## Типи віджетів (вбудовані)

| widget | Поведінка |
|--------|-----------|
| `button` | тап → запит (небезпечні — з підтвердженням) |
| `toggle` | перемикач (сервер сам змінює стан) |
| `slider` | качелька (гучність…), початкове значення через `getter` |
| `media_view` | відповідь-зображення → перегляд zoom/pan + **Поділитися** + **Зберегти в Downloads** |
| `audio` | відповідь-аудіо → програвач + поділитися/зберегти |
| `text_input` | поле вводу + виконати (напр. URL, таймер) |
| `picker` | вибір з варіантів (напр. гарячі клавіші) |

## Структура

```
main.py                 ← точка входу + роутинг екранів
theme.py                ← єдина тема (темна) + хелпери Flet 0.85
core/
├─ api_client.py        ← HTTP-клієнт: TLS-pinning + Bearer + retry
├─ storage.py           ← збереження ПК/токенів (JSON у app-data)
└─ pairing.py           ← парсинг QR-даних
screens/
├─ pair_screen.py       ← підключення ПК (код QR / вручну)
├─ grid_screen.py       ← головна сітка 4-в-ширину
└─ pcs_screen.py        ← «Мої ПК» (перемикання/видалення)
widgets/                ← реалізації типів віджетів (по файлу)
```

## Запуск (розробка, desktop)

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\flet run main.py
```

## Збірка APK (Android)

```powershell
.venv\Scripts\flet build apk
```
APK з'явиться в `build/apk/`. Потрібні Flutter SDK + Android SDK (flet підкаже,
якщо чогось бракує).

> **Перше підключення:** на ПК має бути запущений PC Control, а телефон —
> у тій самій мережі АБО ПК доступний ззовні (проброс порту на білий IP).
